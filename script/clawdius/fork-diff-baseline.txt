# Update this file deliberately - for example after an upstream merge - by re-running:
#   script/clawdius/diff-stat
# and recording the new numbers below. The ratchet (script/clawdius/diff-stat --check, run in CI)

# upstream_commit pins the base by SHA so the ratchet resolves even on a shallow CI checkout that
# has no upstream remote and cannot see the tag name; CI fetches this SHA before running --check.

# dropped an unparseable line and recorded nothing, so a read that LOST a record still reported `complete` - the
# one claim the completeness ladder exists to prevent. Probed against the compiled seam, a torn line returned
# {records:1, sawForeign:false} -> `complete`, while a merely-unmodeled record type returned `partial`: the label

# rule, and two tests pinning torn-vs-live-tail. No new files; isolated to the clawdius-owned reader seam.

# Disposition 2026-07-16 (+0 files, +172 insertions): four MAJOR defects in the journal fix above. The first
# three were holes the same series had already closed elsewhere and reopened here; all four are
# recorded because the fork grew to fix them.
#   1. The live-tail exemption masked terminal corruption. Skipping an unterminated last line is right for a
#      manifest-less run (the launcher is mid-write) and wrong for a terminal one (nothing appends to a finished
#      run, so the same bytes can only be damage). readJournal now takes the lifecycle and exempts the tail only
#      for a live run.
#   2. Journal records were cast, not recognized, so an unchecked `agentId` reached a regex guard that COERCES its
#      argument - AGENT_ID_RE.test(7) tests "7" and passes. A recognizer now validates the shape, and isAgentId
#      narrows from `unknown` rather than trusting a type that was never checked.
#   3. An all-torn journal returned a bare [] - "this mission ran no agents" and "its agents were unreadable" are
#      opposite facts that an unlabeled empty list states identically. The drill-in now returns a labeled
#      MissionAgentList so an EMPTY list can still say `partial`, and the view says which it is.
#   4. None of the above was falsifiable: the tests called only listMissions, so deleting the guards left the suite
#      green. Every guard now has a test that fails without it, verified by mutating each one in turn - which also
