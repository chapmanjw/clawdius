# Clawdius fork-diff ratchet baseline
#
# The fork surface measured against the pinned upstream tag by script/clawdius/diff-stat.
# This baseline is the agreed size of the intentional fork diff: the fork MUST NOT grow beyond it
# without a recorded, reviewed disposition, keeping the diff small, isolated, and auditable.
# Update this file deliberately - for example after an upstream merge - by re-running:
#   script/clawdius/diff-stat
# and recording the new numbers below. The ratchet (script/clawdius/diff-stat --check, run in CI)
# fails when files-changed or insertions exceed these numbers.
#
# The large deletion count is dominated by removing a prebuilt vendor chat extension (a checked-in
# dist bundle); insertions and files-changed are the growth-relevant metrics for the ratchet.
#
# upstream_commit pins the base by SHA so the ratchet resolves even on a shallow CI checkout that
# has no upstream remote and cannot see the tag name; CI fetches this SHA before running --check.
